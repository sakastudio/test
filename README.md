## 使用技術
- HTML5
- CSS3 (アニメーション、グリッド、フレックスボックス)
- Vanilla JavaScript (モーダル、ナビゲーション)
- Vite (開発サーバー・ビルド)

## セットアップ
1. 依存関係をインストール: `npm install`
2. 開発サーバーを起動: `npm run dev`
   - ブラウザで`http://localhost:5173`を開く
3. 本番ビルドを作成: `npm run build`
4. ビルド成果物のローカル確認: `npm run preview`
